# VO Annotations - Voice Over Accessibility Plugin

A Figma plugin for creating and managing voice-over annotations to improve accessibility for users with screen readers and assistive technologies.

## Features

### Annotation Management
- **Create annotations** attached to any Figma element with automatic frame context detection
- **Update annotations** with platform-specific fields (mobile or web)
- **Delete annotations** with automatic cleanup of canvas artifacts
- **Reorder annotations** to control screen reader focus/reading order
- **Sequential IDs** with gap-filling for deleted annotations

### Multi-Platform Support
- **Mobile (iOS/Android)**: VoiceOver and TalkBack fields including Label, Value, Trait, and Hint
- **Web (ARIA)**: aria-label, role, aria-describedby, and tabindex fields
- Platform switching preserves annotation identity while updating field structure

### Canvas Rendering
- **Annotation tables** rendered directly on Figma canvas with platform-specific layouts
- **Numbered badges** on annotated elements showing focus order
- **Smart positioning** with 60px offset from target elements
- **Table stacking** for multiple annotations on the same element

### Frame Detection & Navigation
- **Auto-switch context** when selection moves to a different frame
- **Navigate to frames** across pages with viewport zoom
- **Annotation table selection** navigates back to source frame

### Data Persistence
- **Node plugin data** as authoritative source (survives file saves, copies, version history)
- **Multi-page support** with document-wide annotation loading
- **Legacy data migration** from older storage formats
- **Validation on load** with duplicate removal and error filtering

### Bidirectional Sync
- **Canvas-to-cache sync** detects edits made directly in canvas tables
- **Timestamp-based conflict resolution** (newer wins)
- **Change detection** categorizes annotations as added/removed/modified/unchanged

## Architecture

This plugin uses **Preact Signals** for reactive state management, providing:

- **Automatic reactivity**: Components update automatically when state changes
- **Fine-grained updates**: Only affected components re-render (no cascade re-rendering)
- **Computed values**: Derived state that updates automatically when dependencies change
- **Signal effects**: Side effects with automatic dependency tracking
- **Zero boilerplate**: No manual `useEffect` dependency arrays needed

### State Management

```typescript
// Reactive state with automatic dependency tracking
const annotations = useSignal<Annotation[]>([])
const currentFrameId = useSignal<string | null>(null)

// Computed values update automatically
const frameAnnotations = useComputed(() =>
  annotations.value.filter(a => a.frameId === currentFrameId.value)
)

// Effects run automatically when accessed signals change
useSignalEffect(() => {
  // No manual dependency arrays needed!
  console.log('Frame changed:', currentFrameId.value)
})
```

## Development Guide

*This plugin is built with [Create Figma Plugin](https://yuanqing.github.io/create-figma-plugin/) and uses modern Preact Signals for state management.*

### Pre-requisites

- [Node.js](https://nodejs.org) – v24
- [Figma desktop app](https://figma.com/downloads/)

### Build the plugin

To build the plugin:

```bash
$ npm run build
```

This will generate a [`manifest.json`](https://figma.com/plugin-docs/manifest/) file and a `build/` directory containing the JavaScript bundle(s) for the plugin.

To watch for code changes and rebuild the plugin automatically:

```bash
$ npm run watch
```

### Install the plugin

1. In the Figma desktop app, open a Figma document.
2. Search for and run `Import plugin from manifest…` via the Quick Actions search bar.
3. Select the `manifest.json` file that was generated by the `build` script.

### Debugging

Use `console.log` statements to inspect values in your code.

To open the developer console, search for and run `Show/Hide Console` via the Quick Actions search bar.

### Testing

The project uses Vitest for unit and integration testing:

```
$ npm test              # Run all tests
$ npm run test:watch    # Run tests in watch mode
$ npm run test:coverage # Run tests with coverage report
```

Tests are located in `src/__tests__/` and include:
- **Unit tests**: Validation logic, change detection, field schema mappings
- **Integration tests**: Annotation store CRUD, message routing, canvas operations
- **Mock utilities**: Figma API mocks (`figma.getNodeByIdAsync`, `node.setPluginData`, etc.)

CI runs automatically on pull requests with lint, typecheck, build, and test steps.
